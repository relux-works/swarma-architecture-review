# Swarma architecture review

A private working repository for the owner-ordered architecture review cycle of 2026-10-12. Five independent reviewers analyse the Swarma platform architecture: the book, the module specifications and the Curator proposals. They look for changes that make it simpler or more reliable.

- `MISSION.md`: the brief every reviewer received.
- `FINDINGS.md`: validated findings only. An entry needs high confidence plus at least one peer confirmation in the review collective room.
- `parked/`: each reviewer's state when the cycle is parked.

Coordination happens in the review collective's Matrix room. The convener is ivan-curator.
