# H-RELEASE — All-runtime hosted activation and explicit migration

Owner repository: **curator-agent-launcher**, coordinating separately released project-management and agents-management artifacts. Size: **2**.

Normative clauses: hosted §§1/2/5/6/7/8; CIP-0016 leaves 7–8. Attack surface: advertising partial support or changing dormant defaults into consent.

Acceptance: enable production local receiver lookup only after jointly published versions and all required Claude/Codex/Muse prepare/launch, attach/resume and goal rows pass through actual released entrypoints and registered factories. Record exact source/module/provider/platform tuples, measured/required counts and named unknown/skipped rows. A shape parser, matching digest, login-present row or generic factory is never runtime qualification. Advertise unsupported combinations as unavailable.

Require explicit local-backend migration of prior operator hosted defaults; leave machine defaults refused until upgrade-without-hangup is independently proved. Mixed versions/builds refuse without replacing a live daemon. Document same-user boundary, PTY loss on daemon replacement, source/credential limits and separate future dispatcher opt-in. Preserve legacy task-board claude/codex behavior; wrapper convergence is optional, not an activation prerequisite. Status reads do not rewrite homes or launch sessions.

Tests/control pairs: complete matrix enables the exact matching release tuple; remove any one runtime operation/qualification and public capability must remain unavailable. Valid explicit hosted request works; old/default config and unknown backend do not silently migrate or launch. Compatible live daemon connects; skew refuses with no restart signal. Valid resume succeeds; missing/unreadable/ambiguous/unknown-liveness evidence never creates a new session. Known-bad capability advertisement plant must fail the release checker.

Dependencies/paths: every H leaf, HOST-HOME-CODE, current Curator release and relevant v4/settings/source gates. Launcher help/defaults/capability activation docs and release metadata; receiver advertises only its real operation evidence. Separate signed releases/PRs remain owned by their repositories. Dispatcher/archive/protected cross-account launch and headless task-board spawn are not qualified by this release.
