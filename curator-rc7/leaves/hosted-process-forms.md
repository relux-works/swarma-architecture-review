# H-FORMS — Compose complete hosted provider processes

Owner repository: **skill-agents-management**. Size: **3**, pure process formation and typed restart templates; no daemon lifecycle implementation.

Normative clauses: hosted §§1/3/4/5; CIP-0016 leaf 3; environments §10.2; adopted Codex settings carrier and snapshot descriptor §6.

Attack surface: host-only values or policy being appended after the plan is sealed.

Acceptance: accept already prepared endpoints/private homes/policy values as typed inputs and produce final Claude PTY, Codex private app-server and Muse musepty argv/env. Codex native goals are disabled and endpoint plus typed settings/policy are already in argv; never convert interactive argv later. Muse consumes explicit root_context and backend facts. Relative snapshot paths bind once at composition; no layout inspection or resolve. Emit closed typed restart templates with identity substitution and preserve exact existing channel/MCP/permission semantics. Do not run providers or create/reconnect credentials.

| Positive control | Negative / forbidden effect |
| --- | --- |
| Each supported form produces the exact prepared process and stable sealed identity | Missing/wrong runtime resource, unsupported form or unavailable required fact refuses before exec |
| Valid typed resume substitutes only the permitted identity | Reparsed native tail, hidden host-only flag, extra endpoint or untyped selector refuses |
| Profile MCP and closed session policy compose without collision | Duplicate `-p`, dropped MCP, ambient MCP merge, config rewrite or overlay shadowing refuses |
| Same prepared values yield the same process | Changing endpoint/backend/settings/home/goal mode invalidates identity; no executor recomposition |

Drive public module build/seal/import paths. Plant one omitted prepared endpoint or settings member and prove exact-process comparison catches it. These tests do not qualify actual PTY/app-server behavior.

Dependencies/paths: H-WIRE, HOST-HOME-SPEC, v4 and typed-settings readers; `pkg/agentic/launchboundary*`, `resume.go`, system Claude/Codex/Muse args/env/seal files and plugin adapters. Serialize shared request/identity edits with settings/source carriers; provider-specific pure builders can develop in distinct files. Consumers pin the reviewed module before H-LAUNCHER/H-CLAUDE/H-MUSE/H-CODEX activation.
